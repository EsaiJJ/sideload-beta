How to connect USB debugging, OTG, and Termux on the same phone

Turn on USB debugging first: open Settings → About phone and tap Build number 7 times, then go to Settings → Developer options → USB debugging and switch it on.

From a computer

  1. 1Connect the phone with a USB cable.
  2. 2On the phone, choose File transfer / MTP if asked.
  3. 3Tap Connect USB device here and pick your phone in the browser list.
  4. 4Approve Allow USB debugging? on the phone. Tick “Always allow” to skip it next time.

From another Android phone

  1. 1Use a USB-OTG adapter and plug this phone into the other Android phone.
  2. 2On the other phone, enable USB debugging and allow the USB debugging prompt when it appears.
  3. 3Open this page in Chrome on Android, then tap Connect and choose the device.
  4. 4Keep the page in the foreground while the app is installing.

On this phone (Termux bridge)

  1. 1Enable Wireless Debugging in Developer options.
  2. 2Tap Copy Termux command above, paste it into Termux, and press Enter. Keep Termux open.
  3. 3Choose This phone (Termux) above, match the port, and tap Connect to bridge.
  4. 4Use Pair Wireless Debugging for the pairing port/code, then Connect ADB with the Wireless Debugging port. Approve any prompt on the phone.
WebUSB works in Chromium browsers (Chrome, Edge, Brave) over HTTPS. The Termux bridge uses ws://127.0.0.1 and works in any modern browser on the same phone. If a connection fails, close other ADB tools and try again.
